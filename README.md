# Facial Recognition Attendance System

## 📌 Project Overview

The Facial Recognition Attendance System is an automated attendance management system that uses face recognition technology to identify students and record their attendance.

The system reduces manual attendance work and provides a simple way for teachers to manage and view attendance records.

## 🚀 Features

- Face detection and recognition
- Automatic attendance marking
- Student registration and management
- Teacher dashboard
- Student attendance viewing
- Manual attendance option
- Attendance records stored in CSV files
- Attendance report generation
- Simple and user-friendly interface

## 🛠️ Technologies Used

- Python
- OpenCV
- NumPy
- Pandas
- Tkinter
- Pyttsx3
- Haar Cascade
- Next.js
- TypeScript
- Tailwind CSS
